# @cartridge-engine/init

Scaffold a new ink-cartridge project — a standalone CLI package.

## Usage

```bash
npx ink-cartridge-init <project-name>
```

Creates a project directory with a `package.json` (depending on `ink-cartridge`, `ink`, `react`), a `tsconfig.json`, and a starter `src/index.tsx` screen demo, then runs `npm install`.
